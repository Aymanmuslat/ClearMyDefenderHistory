# ClearMyDefenderHistory

أداة لمسح سجلّ حماية Windows Defender (**Protection history**) على جهازك الشخصي.

## لماذا؟

أحيانًا يُبقي Defender إدخالاً قديمًا في «تاريخ الحماية» لتطبيق حذفته بالفعل،
أو إنذارًا خاطئًا (False Positive) بقي بعد تحديث التعريفات. هذه الأداة تنظّف هذه
الإدخالات.

## كيف تعمل؟

منذ ربيع 2024 غيّرت Microsoft أمان Defender بحيث **لا يمكن حذف ملفات السجلّ
ونظام ويندوز يعمل** — حتى بصلاحيات المسؤول، لأن Defender يقفل الملفات.

الحل الوحيد الحالي: تُنشئ الأداة **مهمّة مجدولة (Scheduled Task) تعمل مرّة واحدة
بحساب SYSTEM عند بدء التشغيل التالي**، فتحذف المجلدات في لحظة الإقلاع قبل أن
يقفلها Defender، ثم تحذف نفسها. لذلك **إعادة تشغيل واحدة ضرورية**.

## ماذا تحذف؟

| المجلد | المحتوى |
|---|---|
| `Scans\History\Service` | سجلّ الفيروسات والبرمجيات المكتشفة |
| `Quarantine` | عناصر الحجر الصحي |
| `Scans\mpenginedb.db*` | قاعدة بيانات تتضمّن سجلّ حظر المجلدات المحمية (CFA) |

## الميزات (v2)

- **فحص أمان:** قبل أي شيء، تتحقّق من وجود تهديد **نشط** (`IsActive`)، وتطلب
  تأكيدًا صريحًا قبل المتابعة — كي لا تُخفى إصابة حقيقية بالخطأ.
- **شفافية:** تعرض بالضبط ما ستحذفه قبل التنفيذ، وتطلب تأكيدك.
- **معالجة أخطاء:** تتحقّق من نجاح إنشاء المهمّة وتُبلغك بوضوح عند الفشل.
- **وضع الإلغاء:** غيّر `$CancelInstead` إلى `$true` لإزالة مهمّة مجدولة سابقة
  دون تنفيذ أي حذف (تراجُع).
- **رفع صلاحيات تلقائي:** لا حاجة لتشغيلها يدويًا كمسؤول.

## الخيارات (أعلى ملف `ClearMyDefenderHistory.cmd`)

| الخيار | الوظيفة |
|---|---|
| `$ClearAV` | حذف سجلّ الفيروسات المكتشفة |
| `$ClearQuarantine` | حذف عناصر الحجر الصحي |
| `$ClearCFA` | حذف سجلّ حظر المجلدات المحمية |
| `$RemoveTask` | حذف المهمّة بعد تشغيلها مرّة واحدة (اتركه `$true`) |
| `$CancelInstead` | `$true` = إزالة مهمّة سابقة والخروج فقط |

> **ملاحظة عن النطاق:** الأداة تنظّف ما يظهر في واجهة «تاريخ الحماية» فقط. لا تمسّ
> سجلّات أحداث النظام (Event Logs) ولا قطاعات القرص ولا آثار تشغيل النظام، ولا
> تُضعِف حماية Defender التي تبقى عاملة كالمعتاد.

## طريقة الاستخدام

1. نزّل `ClearMyDefenderHistory.cmd`.
2. انقر عليه بزرّ الفأرة الأيمن ← **Properties** ← **Unblock** ← **OK**.
3. نقر مزدوج ← اقبل نافذة **UAC**.
4. راجع ما ستحذفه، أكّد، ثم اكتب `y` لإعادة التشغيل.
5. بعد الإقلاع: **Windows Security ← Protection history** ستكون فارغة.

## التحقق بعد إعادة التشغيل

```
schtasks /query /tn ClearMyDefenderHistory
```

ظهور `ERROR: The system cannot find the file specified.` = نجاح (عملت مرّة ثم حذفت نفسها).

## تنبيه

بعض برامج الحماية قد تُنذر عند تنزيل أي سكربت جديد (إنذار خاطئ متوقّع). الشيفرة
مفتوحة بالكامل ويمكنك مراجعتها قبل التشغيل.
